# Antigravity Tool & Multi-Agent Hygiene (Windows / PowerShell)

1. **`ArtifactMetadata` Scope Restriction:** Never provide `ArtifactMetadata` when calling `write_file` or `edit_file` on workspace/repository files. Provide `ArtifactMetadata` strictly when writing markdown artifacts inside `<appDataDir>/brain/<conversation-id>/`.
2. **PowerShell Command Hygiene:** Avoid complex inline `python -c "..."` one-liners containing nested quotes, brackets, or dictionary comprehensions in PowerShell (`run_command`). Prefer invoking the project virtualenv explicitly (`& "<repo>/.venv/Scripts/python.exe" <script.py>`) or reading structured files directly with `read_file`.
3. **Silent Reactive Barrier on Multi-Agent Fan-In:** Antigravity automatically wakes the parent conversation when background subagents or tasks send messages. When waiting on a wave of `N` parallel subagents and a partial `DONE` arrives (`k < N`, with no `BLOCKER` or timer alert), do not poll with `manage_subagents`, `run_command`, or directory listings—acknowledge progress concisely and end the turn with zero tool calls until the wave barrier (`N/N`) or escalation triggers.
4. **Hermetic Test Lockfiles:** Any test creating temporary lockfiles or state markers watched by workspace hooks (such as `.c2c_subagent_lock.json`) must write them strictly inside pytest `tmp_path`, never inside live repository directories.
