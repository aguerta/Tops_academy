# Antigravity Tool & Multi-Agent Hygiene (Windows / PowerShell)

1. **`ArtifactMetadata` Scope Restriction:** Never provide `ArtifactMetadata` when calling `write_file` or `edit_file` on workspace/repository files. Provide `ArtifactMetadata` strictly when writing markdown artifacts inside `<appDataDir>/brain/<conversation-id>/`.
2. **PowerShell Command Hygiene & No `rg` (`ripgrep`):**
   - **`rg` (`ripgrep`) does NOT exist** in this Windows / PowerShell environment. Never invoke `rg` in `run_command` (by main agents or subagents). For text searches across files, use PowerShell's native `Select-String` (e.g., `Select-String -Path <files> -Pattern "<pattern>"`), `git grep -n "<pattern>"`, or a quick Python search script.
   - Avoid complex inline `python -c "..."` one-liners containing nested quotes, brackets, or dictionary comprehensions in PowerShell (`run_command`). Prefer invoking the project virtualenv explicitly (`& "<repo>/.venv/Scripts/python.exe" <script.py>`) or reading structured files directly with `read_file`.
3. **Silent Reactive Barrier on Multi-Agent Fan-In:** Antigravity automatically wakes the parent conversation when background subagents or tasks send messages. When waiting on a wave of `N` parallel subagents and a partial `DONE` arrives (`k < N`, with no `BLOCKER` or timer alert), do not poll with `manage_subagents`, `run_command`, or directory listings—remain completely silent (zero visible text and zero tool calls) until the wave barrier (`N/N`), a `BLOCKER`, or a timer alert triggers.
4. **Hermetic Test Lockfiles:** Any test creating temporary lockfiles or state markers watched by workspace hooks (such as `.c2c_subagent_lock.json`) must write them strictly inside pytest `tmp_path`, never inside live repository directories.
