### [C-01] Definición y Orden de un Sistema de EDOs (Concept)

- **Bloom Level:** Understand
- **Session:** Unidad 4: Definición y Orden de un Sistema de EDOs
- **Prerequisites:** None
- **Evidence Citations:** `TEMA 2.1 (S'EDOS I ).pdf` (page 4)

#### Description & Cognitive Model
Un sistema de ecuaciones diferenciales ordinarias relaciona una variable independiente $t$ con varias variables dependientes $y_1(t), \dots, y_m(t)$ y sus derivadas. El orden del sistema viene determinado por la derivada de mayor orden que figure en cualquiera de sus ecuaciones constituyentes.

#### Fused Distractor Models (6)

| Distractor ID | Trap / Name | Error Type | Severity | Misconception / Omitted Step | Remediation Hint |
|:---|:---|:---:|:---:|:---|:---|
| `D-C01-01` | Confusión entre orden y dimensión | conceptual_swap | high | El orden es igual al número de variables dependientes $m$ | El número de variables dependientes define la dimensión del sistema, no su orden diferencial. |
| `D-C01-02` | Suma de órdenes individuales | conceptual_swap | high | El orden del sistema es la suma de los órdenes de todas las ecuaciones $\sum_{i=1}^m n_i$ | El orden de un sistema de EDOs se define como el máximo orden de derivación presente, no la suma de los órdenes. |
| `D-C01-03` | Confusión con el grado algebraico | conceptual_swap | high | El orden está determinado por la potencia más alta a la que están elevadas las variables | El grado es la potencia algebraica, mientras que el orden es el número de veces que se deriva respecto a la variable independiente. |
| `D-C01-04` | Omisión de derivadas intermedias | conceptual_swap | high | Solo se consideran sistemas donde todas las variables dependientes tienen el mismo orden de derivación | Un sistema puede contener ecuaciones con diferentes órdenes de derivación para distintas variables dependientes. |
| `D-C01-05` | Confusión sobre variable independiente | conceptual_swap | high | Un sistema de EDOs posee múltiples variables independientes respecto a las cuales se derivan las funciones | Si existieran múltiples variables independientes se trataría de un sistema de ecuaciones en derivadas parciales (EDP), no EDO. |
| `D-C01-06` | Criterio de número de soluciones | conceptual_swap | high | El orden equivale directamente a la cantidad de condiciones iniciales por variable independiente sin considerar las derivadas | El número total de constantes arbitrarias y condiciones requeridas depende de la suma de órdenes o dimensión del sistema equivalente de primer orden. |

### [C-02] Representación Matricial y Principio de Superposición en Sistemas Lineales (Concept)

- **Bloom Level:** Understand
- **Session:** Unidad 5: Representación Matricial y Principio de Superposición en Sistemas Lineales
- **Prerequisites:** C-01
- **Evidence Citations:** `TEMA 2.1 (S'EDOS I ).pdf` (page 5)

#### Description & Cognitive Model
Un sistema lineal homogéneo de primer orden se expresa matricialmente como $\dot{X} = AX$. Por el principio de superposición, si $X_1(t), \dots, X_n(t)$ son soluciones linealmente independientes, cualquier combinación lineal $X(t) = \sum_{i=1}^n c_i X_i(t)$ constituye la solución general del sistema.

#### Fused Distractor Models (6)

| Distractor ID | Trap / Name | Error Type | Severity | Misconception / Omitted Step | Remediation Hint |
|:---|:---|:---:|:---:|:---|:---|
| `D-C02-01` | Violación de linealidad en superposición | conceptual_swap | high | $X(t) = c_1 X_1(t) \cdot c_2 X_2(t)$ | El producto de soluciones de un sistema lineal no satisface en general la ecuación diferencial; la combinación lineal requiere suma ponderada. |
| `D-C02-02` | Aplicación errónea a sistemas no lineales | conceptual_swap | high | El principio de superposición se aplica a sistemas no lineales $\dot{X} = f(X)$ | La superposición lineal solo es válida en operadores diferenciales lineales debido a la propiedad distributiva de la derivada. |
| `D-C02-03` | Confusión en dimensiones matriciales | conceptual_swap | high | Para un sistema de dos variables $x, y$, la matriz $A$ es de dimensión $1 \times 2$ | Para relacionar un vector de derivadas $2 \times 1$ con un vector de estado $2 \times 1$, la matriz de coeficientes debe ser cuadrada de $2 \times 2$. |
| `D-C02-04` | Dependencia lineal de soluciones base | conceptual_swap | high | Cualquier conjunto de $n$ soluciones, incluso linealmente dependientes, genera la solución general | Si las soluciones son dependientes, su combinación no abarca el espacio total de soluciones fundamentales del sistema. |
| `D-C02-05` | Confusión de término independiente homogéneo | conceptual_swap | high | El sistema $\dot{X} = AX + B$ con $B \ne 0$ es homogéneo si $B$ es constante | La presencia de un vector de términos independientes no nulo $B$ convierte al sistema en no homogéneo, independientemente de si $B$ es constante. |
| `D-C02-06` | Inversión del orden matricial | conceptual_swap | high | La forma canónica del sistema lineal es $\dot{X} = XA$ | Como $X$ es un vector columna de $n \times 1$, la multiplicación matricial exige que la matriz $A$ de $n \times n$ pre-multiplique al vector $X$. |

### [H-01] Polinomio Característico mediante Enfoque Traza-Determinante (Fact)

- **Bloom Level:** Remember
- **Session:** Unidad 8: Polinomio Característico mediante Enfoque Traza-Determinante
- **Prerequisites:** C-02
- **Evidence Citations:** `TEMA 2.1 (S'EDOS I ).pdf` (page 8), `TEMA 2.3 (S'EDOS II).pdf` (page 7)

#### Description & Cognitive Model
Para una matriz de coeficientes $A = \begin{pmatrix} a & b \\ c & d \end{pmatrix} \in \mathbb{R}^{2 \times 2}$, la ecuación característica $\det(A - \lambda I) = 0$ adopta la forma compacta $\lambda^2 - \operatorname{tr}(A)\lambda + \det(A) = 0$, donde la traza es $\operatorname{tr}(A) = a + d$ y el determinante es $\det(A) = ad - bc$.

#### Fused Distractor Models (12)

| Distractor ID | Trap / Name | Error Type | Severity | Misconception / Omitted Step | Remediation Hint |
|:---|:---|:---:|:---:|:---|:---|
| `D-H01-01` | Error de signo en el término lineal | conceptual_swap | high | $\lambda^2 + \operatorname{tr}(A)\lambda + \det(A) = 0$ | El desarrollo de $(a - \lambda)(d - \lambda) - bc = \lambda^2 - (a+d)\lambda + (ad-bc)$ produce un signo negativo antes de la traza. |
| `D-H01-02` | Error de signo en el término independiente | conceptual_swap | high | $\lambda^2 - \operatorname{tr}(A)\lambda - \det(A) = 0$ | El término independiente del polinomio característico de una matriz de orden 2 corresponde a $+\det(A)$, no a $-\det(A)$. |
| `D-H01-03` | Definición incorrecta de la traza | conceptual_swap | high | $\operatorname{tr}(A) = ad - bc$ | La traza es la suma de los elementos de la diagonal principal $a+d$, mientras que $ad-bc$ es el determinante. |
| `D-H01-04` | Definición incorrecta del determinante | conceptual_swap | high | $\det(A) = a + d$ | El determinante de una matriz $2 \times 2$ es el producto de la diagonal principal menos la diagonal secundaria, no la suma de la diagonal. |
| `D-H01-05` | Intercambio de coeficientes | conceptual_swap | high | $\lambda^2 - \det(A)\lambda + \operatorname{tr}(A) = 0$ | El coeficiente de grado 1 es la traza cambiada de signo y el término de grado 0 es el determinante. |
| `D-H01-06` | Omisión del término cuadrático unitario | conceptual_swap | high | $\operatorname{tr}(A)\lambda^2 - \lambda + \det(A) = 0$ | En una matriz de $2 \times 2$, el polinomio característico es mónico, por lo que el coeficiente de $\lambda^2$ es siempre 1. |
| `D-H01-07` | Error de signo en el polinomio característico | conceptual_swap | high | $p_A(\lambda) = \lambda^2 + \text{tr}(A)\lambda + \det(A)$ | El desarrollo de $\det(A - \lambda I)$ produce $-\text{tr}(A)$ como coeficiente lineal, no $+\text{tr}(A)$. |
| `D-H01-08` | Error en la fórmula del discriminante | conceptual_swap | high | $\Delta = \text{tr}(A)^2 + 4\det(A)$ | El discriminante de la ecuación cuadrática $\lambda^2 - \text{tr}(A)\lambda + \det(A) = 0$ es $(- \text{tr}(A))^2 - 4(1)\det(A) = \text{tr}(A)^2 - 4\det(A)$. |
| `D-H01-09` | Inversión de relaciones de Cardano-Vieta | conceptual_swap | high | $\lambda_1 + \lambda_2 = \det(A)$ y $\lambda_1 \lambda_2 = \text{tr}(A)$ | La suma de los autovalores es la traza (suma de elementos diagonales) y el producto es el determinante. |
| `D-H01-10` | Error en la fórmula cuadrática de autovalores | conceptual_swap | high | $\lambda_{1,2} = \text{tr}(A) \pm \sqrt{\Delta}$ | La fórmula general para la resolución de la ecuación cuadrática mónico requiere dividir entre $2a = 2$. |
| `D-H01-11` | Confusión de definición de traza | conceptual_swap | high | $\text{tr}(A) = a_{12} + a_{21}$ | La traza es la suma de los elementos de la diagonal principal ($a_{11} + a_{22}$), no de la diagonal secundaria. |
| `D-H01-12` | Confusión entre determinante y traza para autovalores nulos | conceptual_swap | high | $\det(A) = 0 \Rightarrow \lambda_1 = \lambda_2 = 0$ | Si $\det(A) = \lambda_1 \lambda_2 = 0$, al menos un autovalor es nulo, pero el otro es igual a $\text{tr}(A)$. |

### [C-03] Estructura de la Solución con Autovalores Reales y Distintos (Caso I) (Concept)

- **Bloom Level:** Understand
- **Session:** Unidad 9: Estructura de la Solución con Autovalores Reales y Distintos (Caso I)
- **Prerequisites:** H-01
- **Evidence Citations:** `TEMA 2.1 (S'EDOS I ).pdf` (page 9)

#### Description & Cognitive Model
Cuando la matriz $A$ posee autovalores reales y distintos $\lambda_1 \ne \lambda_2$ con autovectores asociados $v_1, v_2$, las soluciones elementales $X_1(t) = v_1 e^{\lambda_1 t}$ y $X_2(t) = v_2 e^{\lambda_2 t}$ son linealmente independientes, formando la solución general $X(t) = c_1 e^{\lambda_1 t} v_1 + c_2 e^{\lambda_2 t} v_2$.

#### Fused Distractor Models (6)

| Distractor ID | Trap / Name | Error Type | Severity | Misconception / Omitted Step | Remediation Hint |
|:---|:---|:---:|:---:|:---|:---|
| `D-C03-01` | Exponente sin variable temporal | conceptual_swap | high | $X(t) = c_1 e^{\lambda_1} v_1 + c_2 e^{\lambda_2} v_2$ | La solución depende del tiempo $t$; sin la variable temporal en el exponente la expresión no es una función de $t$ ni satisface $\dot{X} = AX$. |
| `D-C03-02` | Asociación cruzada de autovectores | conceptual_swap | high | $X(t) = c_1 e^{\lambda_1 t} v_2 + c_2 e^{\lambda_2 t} v_1$ | Cada factor exponencial $e^{\lambda_i t}$ debe multiplicarse estrictamente por el autovector $v_i$ asociado a ese mismo autovalor $\lambda_i$. |
| `D-C03-03` | Producto escalar en lugar de combinación lineal | conceptual_swap | high | $X(t) = (v_1^T v_2) e^{(\lambda_1 + \lambda_2)t}$ | La solución general en $\mathbb{R}^2$ requiere un espacio vectorial bidimensional generado por la combinación lineal de los dos vectores columna. |
| `D-C03-04` | Suposición de autovectores dependientes | conceptual_swap | high | Los autovectores asociados a autovalores reales distintos son linealmente dependientes | Un teorema fundamental del álgebra lineal garantiza que autovectores correspondientes a autovalores distintos son siempre linealmente independientes. |
| `D-C03-05` | Omisión de constantes arbitrarias | conceptual_swap | high | $X(t) = e^{\lambda_1 t} v_1 + e^{\lambda_2 t} v_2$ | Para abarcar todas las posibles condiciones iniciales se requieren dos constantes arbitrarias esenciales $c_1, c_2$. |
| `D-C03-06` | Inclusión de términos polinomiales en Caso I | conceptual_swap | high | $X(t) = c_1 e^{\lambda_1 t} v_1 + c_2 t e^{\lambda_2 t} v_2$ | Los términos con factor secular $t$ solo surgen en el Caso III cuando los autovalores son repetidos y falta multiplicidad geométrica. |

### [C-05] Autovalores Reales Repetidos y Autovectores Generalizados (Caso III) (Concept)

- **Prerequisites:** H-01
- **Evidence Citations:** `TEMA 2.1 (S'EDOS I ).pdf` (page 11)

#### Description & Cognitive Model
Cuando la matriz $A$ posee autovalores reales repetidos $\lambda_1 = \lambda_2$ y solo existe un autovector independiente $v_1$, se determina un autovector generalizado $v_2$ que satisface $(A - \lambda_1 I)v_2 = v_1$. La solución general adquiere la forma secular $X(t) = c_1 e^{\lambda_1 t} v_1 + c_2 e^{\lambda_1 t}(v_2 + v_1 t)$.

### [C-06] Estructura de la Solución de Sistemas No Homogéneos (Concept)

- **Bloom Level:** Understand
- **Session:** Unidad 12: Estructura de la Solución de Sistemas No Homogéneos
- **Prerequisites:** C-03
- **Evidence Citations:** `TEMA 2.1 (S'EDOS I ).pdf` (page 12)

#### Description & Cognitive Model
La solución general de un sistema no homogéneo $\dot{X} = AX + B$ se descompone como $X(t) = X_h(t) + X_p(t)$, donde $X_h(t)$ es la solución complementaria (homogénea) y $X_p(t)$ es una solución particular. Si $B$ es un vector constante y $\det(A) \ne 0$, la solución particular es el punto de equilibrio constante $X_p = -A^{-1}B$.

#### Fused Distractor Models (6)

| Distractor ID | Trap / Name | Error Type | Severity | Misconception / Omitted Step | Remediation Hint |
|:---|:---|:---:|:---:|:---|:---|
| `D-C06-01` | Error de signo en la solución particular constante | conceptual_swap | high | $X_p = A^{-1}B$ | En el equilibrio $\dot{X} = 0 \Rightarrow AX_p + B = 0 \Rightarrow AX_p = -B \Rightarrow X_p = -A^{-1}B$; se requiere el signo negativo. |
| `D-C06-02` | Inversión incorrecta en producto matricial | conceptual_swap | high | $X_p = -B A^{-1}$ | La matriz $A$ pre-multiplica a $X_p$, por lo que su inversa $A^{-1}$ debe pre-multiplicar al vector $B$. |
| `D-C06-03` | Uso de fórmula constante para términos no constantes | conceptual_swap | high | Si $B(t) = \begin{pmatrix} 2t \\ t \end{pmatrix}$, entonces $X_p(t) = -A^{-1}B(t)$ | Si $B(t)$ varía con el tiempo, $\dot{X}_p(t) \ne 0$, por lo que $AX_p + B(t) \ne 0$; se debe emplear coeficientes indeterminados. |
| `D-C06-04` | Confusión entre solución complementaria y general | conceptual_swap | high | $X(t) = X_p(t)$ sin incluir la parte homogénea $X_h(t)$ | La solución particular no contiene constantes arbitrarias; omitir la solución complementaria impide ajustar las condiciones iniciales del sistema. |
| `D-C06-05` | Suposición de existencia con determinante nulo | conceptual_swap | high | La fórmula $X_p = -A^{-1}B$ es válida para matrices singulares con $\det(A) = 0$ | Si la matriz de coeficientes es singular, $A^{-1}$ no existe y el sistema puede no tener un punto de equilibrio aislado único. |
| `D-C06-06` | Confusión de homogeneidad | conceptual_swap | high | El sistema $\dot{X} = AX + B$ es homogéneo cuando $X_p = 0$ | La homogeneidad es una propiedad de la ecuación diferencial ($\dot{X} - AX = 0$ frente a $\dot{X} - AX = B$), no de la anulación fortuita de una solución. |

### [C-07] Linealización de Sistemas Autónomos No Lineales mediante Jacobiano (Concept)

- **Prerequisites:** C-02
- **Evidence Citations:** `TEMA 2.1 (S'EDOS I ).pdf` (page 13)

#### Description & Cognitive Model
Para un sistema autónomo no lineal $\dot{x} = f(x, y), \dot{y} = g(x, y)$ con punto de equilibrio $(x^*, y^*)$ donde $f(x^*, y^*) = g(x^*, y^*) = 0$, la aproximación lineal de primer orden de Taylor viene dada por $\dot{X} \approx J(x^*, y^*) (X - X^*)$, donde $J = \begin{pmatrix} \partial f/\partial x & \partial f/\partial y \\ \partial g/\partial x & \partial g/\partial y \end{pmatrix}$ es la matriz jacobiana.

### [C-13] Criterio Cualitativo de Clasificación de Puntos de Equilibrio en el Plano Traza-Determinante (Concept)

- **Bloom Level:** Analyze

- **Prerequisites:** H-01, C-12
- **Evidence Citations:** `TEMA 2.3 (S'EDOS II).pdf` (page 8)

#### Description & Cognitive Model
La topología y estabilidad de un punto de equilibrio lineal en $\mathbb{R}^2$ se determinan a partir de los signos de $\det(A)$, $\text{tr}(A)$ y el discriminante $\Delta$: un $\det(A) < 0$ genera un punto de silla inestable con autovalores reales de signos opuestos; un $\det(A) > 0$ con $\Delta > 0$ define nodos (estable si $\text{tr}(A) < 0$, inestable si $\text{tr}(A) > 0$); mientras que $\Delta < 0$ produce focos espirales (o un vórtice/centro neutro si $\text{tr}(A) = 0$).

#### Fused Distractor Models (6)

| Distractor ID | Trap / Name | Error Type | Severity | Misconception / Omitted Step | Remediation Hint |
|:---|:---|:---:|:---:|:---|:---|
| `D-C13-01` | Clasificación errónea del punto de silla | conceptual_swap | high | $\det(A) < 0 \Rightarrow \text{nodo estable}$ | Cuando $\det(A) = \lambda_1 \lambda_2 < 0$, los autovalores tienen signos opuestos ($\lambda_1 > 0 > \lambda_2$), lo que genera siempre una ensilladura inestable. |
| `D-C13-02` | Error en condición de estabilidad de foco espiral | conceptual_swap | high | $\Delta < 0 \text{ y } \text{tr}(A) > 0 \Rightarrow \text{espiral asintóticamente estable}$ | La parte real de los autovalores complejos es $p = \frac{\text{tr}(A)}{2}$; si $\text{tr}(A) > 0$, la parte real es positiva y la espiral diverge (es inestable). |
| `D-C13-03` | Condición de centro o vórtice errónea | conceptual_swap | high | $\text{tr}(A) \neq 0 \text{ y } \Delta < 0 \Rightarrow \text{vórtice}$ | Un centro o vórtice requiere autovalores imaginarios puros ($p=0$), lo cual se cumple estrictamente cuando $\text{tr}(A) = 0$ y $\det(A) > 0$. |
| `D-C13-04` | Confusión entre nodo propio y nodo genérico | conceptual_swap | high | $\Delta = 0 \Rightarrow \text{foco espiral}$ | Cuando $\Delta = 0$, las raíces son reales e iguales ($\lambda_1 = \lambda_2$), produciendo un nodo propio o estrella, no un foco. |
| `D-C13-05` | Confusión sobre autovalores negativos | conceptual_swap | high | $\lambda_1 < 0 \text{ y } \lambda_2 < 0 \Rightarrow \det(A) < 0$ | El producto de dos números reales negativos es estrictamente positivo, por lo que un nodo estable siempre tiene $\det(A) > 0$. |
| `D-C13-06` | Identificación de repulsor versus atractor | conceptual_swap | high | $\text{tr}(A) < 0 \text{ y } \det(A) > 0 \Rightarrow \text{repulsor}$ | Si todos los autovalores tienen parte real negativa ($\text{tr}(A) < 0$ y $\det(A) > 0$), las trayectorias convergen al punto, tratándose de un atractor. |
